# Mora Homebrew tap

This tap is currently private. The signed-app Cask on this branch replaces the obsolete v0.4 raw CLI package. It installs the signed Mora memory CLI app and links `mora`; it does not install the desktop companion.

After this change is merged, users with access to this repository can install:

```sh
brew tap pyranthus-hq/tap
brew install --cask pyranthus-hq/tap/mora
mora version
```

Public installation requires a separate decision to publish the tap. Do not expose private repository history just to enable installation.

## Existing installations

Do not use `--adopt`, `--force`, or remove quarantine. If you already have Mora installed, first use the signed-app uninstaller documented in the [Mora guide](https://github.com/pyranthus-hq/mora/blob/main/docs/guide.md), or uninstall the old Brew package if Brew owns it. Remove only the installation; preserve your vault, configuration, state, tokens, and backups. The new Cask refuses a conflicting app in `~/Applications` and lets Homebrew reject unmanaged destination files.

## Updates

```sh
brew update
brew upgrade --cask pyranthus-hq/tap/mora
```

For Mora's own scheduled updater:

```sh
mora upgrade --policy auto
mora schedule install update-daily
mora schedule list
mora upgrade --status
```

Installing this Cask alone does not install a schedule or configure connectors. Scheduled updates only deliver published Mora releases. Avoid reinstalling an older Cask over an app already updated by Mora; wait for the tap to catch up.

## Uninstall

```sh
brew uninstall --cask pyranthus-hq/tap/mora
```

The Cask removes its app and command link. It has no `zap` stanza and preserves user data. If you enabled Mora schedules, manage those separately with `mora schedule` before uninstalling.

## Maintaining the Cask

The Cask is generated by `cmd/gencask` in the Mora repository from the exact published release's `checksums-app.txt`. The Mora release-preparation workflow verifies publication, the checksum manifest signature, and both app archives before opening a tap PR. Merge remains a reviewed action. Never switch this Cask to raw CLI archives or add quarantine removal.
